E-commerce Sales Analysis Using SQL

Project Overview

This project analyzes e-commerce purchase data using SQL and Google BigQuery. The objective is to identify sales trends, understand geographical revenue distribution, and discover the best-performing products.

Objectives

- Calculate total purchase revenue.
- Identify the country generating the highest revenue.
- Find the top products by revenue.
- Analyze monthly revenue and month-over-month growth.
- Extract meaningful business insights from the data.

Tools Used

- SQL
- Google BigQuery
- Visual Studio Code
- Git and GitHub

Key Findings

1. Total Revenue

Total recorded purchase revenue was $362,165.00 USD.

2. Revenue by Country

The United States generated the highest revenue, contributing $160,573.00 USD.

3. Top Product

The highest-revenue product was Google Zip Hoodie F/C, generating $13,788.00 USD.

4. Monthly Revenue Growth

- November 2020 revenue: $144,260.00
- December 2020 revenue: $160,555.00
- January 2021 revenue: $57,350.00
- Revenue increased by 11.3% from November to December 2020.

December 2020 recorded the highest revenue among the three months shown in the query results.

Key Insights

- The United States was the leading revenue-generating country.
- Google Zip Hoodie F/C was the top product by revenue.
- Revenue increased in December 2020 but declined significantly in January 2021.

Conclusion

This project demonstrates how SQL can be used to analyze e-commerce data and generate business insights. The analysis covers overall revenue, country-wise performance, product performance, and monthly revenue changes.
