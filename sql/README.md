SQL Queries

This folder contains SQL queries used for the E-commerce Sales Analysis project.

Queries Included

1. "01_data_exploration.sql" – Explore the dataset.
2. "02_total_revenue.sql" – Calculate total revenue.
3. "03_revenue_by_country.sql" – Analyze revenue by country.
4. "04_top_products.sql" – Identify top-selling products.
5. "05_monthly_growth.sql" – Analyze monthly revenue growth.

Tool Used

Google BigQuery
